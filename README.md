## Hey, I'm Mo.

I'm a staff-level full-stack engineer, product builder, and author in Colorado. I've spent **14+ years building software and leading engineering teams**. I still like being close enough to the code to follow a weird bug from the interface to the database.

**Next.js, TypeScript, and applied AI** are my home base. I care about how a product feels, what happens when it breaks, and whether it actually makes someone's day better. That curiosity has turned into agent tools, native apps, accessibility projects, and a couple of books.

## A few things I care about

- **Own the whole problem.** Product decisions, frontend, APIs, data, deployment, and the rough edges after launch.
- **Keep people in control.** Consent, understandable permissions, accessible interfaces, and a way to stop.
- **Make the system explain itself.** Clear state, useful logs, reproducible tests, and failure modes you can reason about.
- **Help the next person.** Write down the tradeoffs, share what I learn, and leave the code easier to work in.
